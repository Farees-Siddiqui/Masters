# PaddleOCR / PP-StructureV3 -- isolated venv, GPU.
#
#   python3 -m venv .venv
#   .venv/bin/pip install paddlepaddle-gpu==3.2.1 \
#       -i https://www.paddlepaddle.org.cn/packages/stable/cu126/
#   .venv/bin/pip install -r requirements.txt
#
# paddlepaddle-gpu is NOT on PyPI -- it comes from the paddlepaddle.org.cn index,
# which is why it is a separate command above rather than a line in this file.
# That mirror is slow: the wheel took ~20 min here.
#
# cu126 for the same reason as every other engine: CUDA 13 dropped Volta.
# Verified in this venv -- paddle 3.2.1, is_compiled_with_cuda() True,
# 4 GPUs, get_device_capability(0) == (7, 0).
#
# Model weights are NOT pip-installed. PP-StructureV3 pulls them on first use
# into ~/.paddlex/official_models/ (~6.8 GB here, already cached). Pipeline
# construction costs ~116 s even fully cached, because it builds every stage
# (layout, OCR det/rec, table cell det, formula, chart-to-table, orientation).
#
# Run it as: CUDA_VISIBLE_DEVICES=N python run_paddle.py --device gpu:0
#
# Note on VRAM: `paddle.device.cuda.max_memory_allocated(0)` works fine, but the
# index must be the card in use. Running `--device gpu:3` while querying index 0
# reports ~2 KB because index 0 is an idle card. Always run as
# CUDA_VISIBLE_DEVICES=N with --device gpu:0. Measured: ~7.0 GB allocator peak
# (nvidia-smi shows ~11.6 GB, which includes context + allocator reserve).
