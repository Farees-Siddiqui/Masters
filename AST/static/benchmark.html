Metric
F1 vs. OCR noise

Results

Synthetic sweep on a fixed AST: paragraphs are split into OCR “lines,” characters corrupted at each noise rate, scored against the known box→node owner. Gold is built from the AST's own text, so this measures robustness to character noise — not the cross-engine task. Re-generate with python -m benchmark synthetic.

Overall — token-level

F1(µ) pools every token across documents (long docs pull harder); F1(M) is the per-document mean (every doc weighted equally). A gap between them means per-document variance the single number is hiding.

Per-document

One corpus number can be carried by a single easy document. This is the spread it averages over.

Prose strata — F1

Regions an AST node genuinely owns. Higher is better.

Furniture strata — abstention accuracy

Page numbers, figure interiors: no node owns these. 1.000 = correctly ignored; 0.000 = a source was invented for every token.

Oracle report

Gold is derived, so it is reported rather than assumed. Nodes the text layer cannot place (LaTeX formulas, image refs) are excluded from gold, not guessed — which makes this benchmark easier than reality by the amount shown.
