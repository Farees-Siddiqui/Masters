## 1. v1 benchmark: false-attribution contamination — FIXED

**Bug (proven live on resnet):** the oracle fails to place ~24% of nodes
(LaTeX, `![img]` refs, short markers). Their tokens became gold-NULL, so an
aligner *correctly* matching them was charged a false attribution. 458 of 477
of resnet's "false attributions" pointed at a node the oracle itself couldn't
place — 96% contamination.

**Fix** (`benchmark/oracle.py`, `token_metrics.py`, `real.py`):
- gold-NULL token whose *predicted* node is unplaced → `n_excluded_unverifiable`, not false_attrib/fp
- `_locate` returns `(start, end, ratio, exact)`; `OracleReport` gains
  `placement_meta` (per-node start/end/ratio/exact), `unplaced_nodes`, `placed_node_ids`
- Known residual bias (documented in code): contamination is only detectable
  when the aligner points at an unplaced node; abstentions there still score tn.

**Corpus impact** (`results_real.json` → `results_real_v2.json`, both kept):

| metric | stream | similarity |
|---|---|---|
| F1 micro | 0.946 → 0.965 | 0.898 → 0.912 |
| null_accuracy | 0.366 → 0.700 | 0.346 → 0.560 |
| false_attribution_rate | 0.634 → 0.300 | 0.655 → 0.440 |

75% of stream's old FA signal was artifact; a real ~0.30 survives.
`aside_text` (pure recall failure) and most `chart`/`algorithm` failures are real.

## 2. v1 benchmark: hyphenated-token geometry — FIXED

pdfium encodes line-break hyphens as U+FFFE *inside* the word, so
"compet-/itive" was one token with a 654px bbox spanning two lines →
(a) wrong center-containment box assignment, (b) dark double-highlight bands
in the annotate UI. Now: `Token.fragments` (split at U+FFFE / U+00AD),
`boxes_to_tokens` votes by fragment centers, annotate payload/overlay draw
per-fragment rects. Stream text md5-identical (no gold shifted); only 2/9,650
resnet assignments changed, both corrections.

## 3. Annotation tool — NEW (`/annotate`)

- `app/annotate.py` (router; wired in `main.py`), `static/annotate.{html,css,js}`
- Three queues per doc, all "machine proposes, human confirms":
  - **excluded** — unplaced nodes: click owning box(es) / absent / skip.
    Box suggestions by bag-of-words overlap with box OCR text.
  - **nulls** — boxes with ownerless tokens: furniture / assign node.
  - **audit** — oracle placements, fuzzy-first: accept / reject.
- Keyboard: j/k navigate, a/r/x/s verdicts, u undo; verdicts save immediately to
  `layout_output/<doc>/annotations.json` (NOTE: `layout_output/` is gitignored —
  annotations.json must be force-added or the gold is lost).
- resnet already has **36 audit accepts** (done by hand in this session).

## 4. benchmark_v2-0 — NEW (`benchmark_v2_0/`)

Node-level localization: gold is `node -> {box keys} | ABSENT`, three tiers
(**human** > **audited** > unverified **oracle**, majority-token-ownership for
oracle boxes; every report prints tier composition). Score = pixel-area IoU of
box unions ≥ 0.5 → **localization accuracy**, plus mean IoU, missed, absent
accuracy, **false claim rate** (furniture boxes claimed), broken down by node
kind (prose/heading/formula/table/image/marker).

Run: `python -m benchmark_v2_0 --docs resnet | --all [--human-only] [--out f.json]`

**10-doc baseline** (`results_v2_all.json`, pre-fragment-fix code, 3% verified):

| method | loc.acc | false.claim |
|---|---|---|
| stream | 0.934 | 0.531 |
| similarity | 0.889 | 0.694 |

Findings: stream wins overall but **loses tables 0.375 vs 0.875** (complementary
failure modes, n=8 so unconfirmed); **adam is the outlier doc** (0.818/0.693 —
maths-heavy, thin gold); formula/table columns nearly empty until the excluded
queues are annotated.
